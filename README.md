# team-blue/php-client-mock

Mock REST and SOAP clients for testing PHP applications.

Provides `RestClientMock`, `GuzzleClientMock` and `SoapClientMock` plus a fluent mock layer (`Mock`, `MockMethod`, `MockLogic`, `MockPersister`) to record, replay and persist HTTP/SOAP interactions in your test suite. Works together with [`team-blue/php-util`](https://github.com/teamdotblue/php-util) and [`team-blue/php-value-objects`](https://github.com/teamdotblue/php-value-objects).

## Installation

```bash
composer require team-blue/php-client-mock
```
